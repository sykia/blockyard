# Blockyard 0.4.1

A new Minecraft-inspired application icon: a voxel grass block with a diamond pickaxe.

- Updated the application, installer, taskbar, launcher sidebar and browser icons.
- Included the full-resolution transparent PNG source and desktop icon formats.
- Windows NSIS installer and Linux AppImage, DEB, RPM and Arch packages.
- Signed updater artifacts, latest.json and SHA-256 checksums.

Windows installers are not Authenticode signed. This release changes branding only; launcher behavior is based on 0.4.0.
